## Login UI

A login interface built with HTML/CSS.

**Live Demo:** (https://timothy-dev-tech.github.io/LOGIN-PAGE-PROJECT/)

## Overview
This project is part of my frontend development journey with a strong focus on clean design.


## Features

- Email and password fields.
- Custom checkbox styling for "Remember me"
- Social sign-in row (Google, Facebook, GitHub)
- Copyright footer

## Tech Stack

- HTML5
- CSS3
